# Charter Compass NYC

A single-page explorer for every NYC charter school (299 in 2025–26). Pick a lens (Parent, Teacher, Student or Enterprise) and the list, headline stats and "what to check next" guidance change to match.

## Run it

The page loads its data with `fetch`, so serve the folder instead of opening the file directly:

```sh
python3 -m http.server 8000
# open http://localhost:8000
```

There's no build step for the page. `index.html` is vanilla JS, with Leaflet and markercluster loaded from cdnjs.

## Data

`data/` is generated by `scripts/build_data.py`, which downloads every source fresh:

| File | Source |
|---|---|
| `schools.json` | NYSED Charter School Directory 2025–26 (roster, district, year, authorizer), joined on the state BEDS code to NCES Common Core of Data 2022–23 to 2024–25 (address, coordinates, grades, enrollment, teachers) |
| `boroughs.geojson` | NYC Open Data, Borough Boundaries (`gthc-hcne`), simplified |
| `districts.geojson` | NYC Open Data, School Districts (`8ugf-3d8u`), simplified |

To rebuild:

```sh
python3 -m venv .venv && .venv/bin/pip install openpyxl shapely
.venv/bin/python scripts/build_data.py
```

Accuracy notes:
- 281 of 299 schools are pinned to their NCES address. The other 18 opened in 2025 or open in 2026, so they aren't in federal data yet. Each is placed at a deterministic spot inside its district polygon and drawn with a dashed ring.
- Networks are inferred from shared name prefixes (the `NETWORKS` list in the build script).
- Not included yet: test scores, lottery odds, salaries, graduation rates. Each school profile links to its data.nysed.gov page.

Map tiles: Esri World Light/Dark Gray Canvas (no API key).
